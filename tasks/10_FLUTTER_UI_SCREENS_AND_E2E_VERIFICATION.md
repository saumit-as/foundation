## 3. Step-by-Step Implementation Instructions

### Step 3.1: Screen 1 — 1-Scan QR Device Onboarding (`qr_onboarding_screen.dart`)
- Uses `MobileScanner` on Android (plus a "Paste Pairing JSON" field for Linux/Windows Desktop) to read the JSON bundle generated by `uv run python -m app.cli register-device --qr`.
- Saves credentials to `CredentialsStore`, triggers `OutboxFlusher.syncDelta()`, and navigates to the main `AppShell`.

### Step 3.2: Screen 2 — Fast Scratchpad, Active Book Session & Marginalia (`scratchpad_screen.dart`, `active_book_session_banner.dart`, `capture_card.dart`)
- **Zero-Tap Composer:** Auto-focused `TextField` supporting `#tags`, voice-memo recording button, and **Multi-Page Burst Book Scan** button (`CunningDocumentScanner.getPictures()`).
- **Sticky Reading Session Banner (`ActiveBookSessionBanner`):** Displays the active book (`LocalReadingSessions` where `isActive == true`, e.g., *"📖 Active Book: Crafting Interpreters"*), allows starting/ending a book session in 1 tap, and automatically attaches `readingSessionId` and `pageRange` to every scan.
- **Capture Stream (`CaptureCard`):**
  - Displays sync/processing badge (`⚡ Local Pending`, `⏳ Indexing Multimodal`, `⚠️ Partial — Rescue in Browser`, `✨ Spark Linked`).
  - Displays immutable `rawText` prominently.
  - For `audio_memo`, renders the bulleted **Voice Distillation Card** (`voiceDistillationJson` summary bullets + action items) directly above the audio player and collapsible verbatim `transcriptText`.
  - Includes an inline **"Add Follow-up / Marginalia"** composer that appends rows to `LocalCaptureAnnotations` below the original note without altering `rawText`.
  - Collapsible *"Extracted Context"* drawer showing `ocrText`, `transcriptText`, and `autoTags`.

### Step 3.3: Screen 3 — AI Sparks, Graph Backlinks & Vault Export (`sparks_screen.dart`)
- Responsive split-pane layout on Desktop (`width >= 800`) and master-detail sheet on Mobile.
- Renders `sparkMarkdown` via `FlutterMarkdown`, lists linked source `LocalCaptures` cards, and provides a **"Promote / Export to Markdown Vault"** button (`GET /api/v1/sparks/{id}/export.md`) that writes the YAML frontmatter + `[[wiki-link]]` `.md` file to the user's chosen local folder.

### Step 3.4: Screen 4 — Multimodal Hybrid Search & "Ask Memoria" RAG (`search_and_ask_screen.dart`)
- Segmented toggle at the top: **`🔍 Hybrid Search`** vs. **`🧠 Ask Memoria (RAG)`**.
- **Hybrid Search Mode:** Calls `POST /api/v1/search` when online (falling back to local Drift SQLite `LIKE` search when offline), badges each result with its matched modality (`video_reel`, `book_page`, `pdf_document`, `audio_memo`, `ai_spark`), and allows selecting $\ge 2$ results to click **"✨ Synthesize Selected into Spark"** (`POST /api/v1/sparks/synthesize`).
- **Ask Memoria Mode:** Calls `POST /api/v1/search/ask`, renders the cited Markdown synthesis, shows clickable source chips, and includes a **"Save Answer as Spark"** toggle.

### Step 3.5: Screen 5 — Morning / Evening Triage Deck (`triage_deck_screen.dart`)
- Card-swipe interface on Mobile and keyboard hotkey listener (`J`/`K` navigate, `P` Pin to Project, `E` Archive, `X` Dismiss, `Space` Keep) on Desktop.
- Calls `POST /api/v1/triage/{id}/decision` (or queues `TRIAGE_DECISION` in `OutboxSyncQueue` when offline).

### Step 3.6: Screen 6 — OS Share Sheet Receiver (`share_receiver_sheet.dart`) & Navigation Shell (`main.dart`)
- Listens to `ReceiveSharingIntent.instance.getMediaStream()` and `getInitialMedia()` on Android.
- Opens a modal bottom sheet pre-filled with the shared URL/image/PDF, allowing an optional 1-line note or `#tag` and saving to Drift SQLite in `<15ms`.
