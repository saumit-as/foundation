# 02_DATABASE_AND_VECTOR_SCHEMA.md
> **DATABASE & MULTIMODAL VECTOR SCHEMA SPECIFICATION**
> This document defines the exact relational, full-text, and vector schemas for both the Home Server (`PostgreSQL 16 + pgvector`) and the Edge Clients (`Flutter Drift SQLite` and `WXT IndexedDB/Storage`). Coding agents must implement migrations (`Alembic` on server, `Drift` schema versions on client) strictly matching these definitions.

---

## 1. Architectural Invariants for Storage
1. **Client-Generated UUIDv7 Primary Keys:** All primary keys (`id`) for `captures` and `media_assets` are generated on the client at capture time using **UUIDv7** (time-ordered UUIDs). This guarantees chronological B-Tree locality and zero-collision idempotent upserts (`ON CONFLICT (id) DO NOTHING`).
2. **Strict Immutability of User Raw Data:** Rows in `captures` represent `user_raw` input. Background workers may update `processing_status`, `extracted_text`, `transcript_text`, `ocr_text`, and `auto_tags`, but MUST NEVER overwrite `raw_text` or `source_url`.
3. **Non-Destructive AI Sparks:** AI syntheses generated by `gpt-6-luna` live in a dedicated `ai_sparks` table and link to parent `captures` (or other `ai_sparks`) through the polymorphic `document_links` table.
4. **Full `768d` Normalized Vectors:** All `pgvector` columns are defined as `VECTOR(768)` corresponding to L2-normalized outputs from `google/embeddinggemma-2` (`bfloat16`/`float32`), indexed via **HNSW (`vector_cosine_ops`)**.

```sql
CREATE TABLE embeddings (
```

### 2.5 Auto-Incrementing `sync_version` Trigger (Delta Sync Cursor)
```sql
CREATE SEQUENCE IF NOT EXISTS global_sync_seq START 1;

CREATE OR REPLACE FUNCTION bump_sync_version()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    NEW.sync_version = nextval('global_sync_seq');
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

CREATE TRIGGER trg_captures_sync_version
BEFORE INSERT OR UPDATE ON captures
FOR EACH ROW EXECUTE FUNCTION bump_sync_version();

CREATE TRIGGER trg_sparks_sync_version
BEFORE INSERT OR UPDATE ON ai_sparks
FOR EACH ROW EXECUTE FUNCTION bump_sync_version();

CREATE TRIGGER trg_reminders_sync_version
BEFORE INSERT OR UPDATE ON reminders
FOR EACH ROW EXECUTE FUNCTION bump_sync_version();

CREATE TRIGGER trg_reading_sessions_sync_version
BEFORE INSERT OR UPDATE ON reading_sessions
FOR EACH ROW EXECUTE FUNCTION bump_sync_version();

CREATE TRIGGER trg_capture_annotations_sync_version
BEFORE INSERT OR UPDATE ON capture_annotations
FOR EACH ROW EXECUTE FUNCTION bump_sync_version();
```

## 5. Hybrid Retrieval SQL Query (Vector Cosine + BM25 RRF + Persona Project Boost)

The backend search service (`app/services/search.py`) MUST execute this exact Reciprocal Rank Fusion (RRF, $k=60$) query to combine `EmbeddingGemma 2` multimodal semantic similarity (deduplicated to the highest-scoring chunk per item) with exact keyword matches across both `captures` and `ai_sparks`, plus a `1.15x` boost for items matching active projects/tags in `persona.json`:

```sql
WITH best_vector_per_item AS (
    SELECT DISTINCT ON (e.owner_id, e.owner_table)
        e.owner_id,
        e.owner_table,
        e.modality_composition,
        e.chunk_preview_text,
        1 - (e.embedding <=> :query_vector::vector(768)) AS cosine_sim
    FROM embeddings e
    WHERE 1 - (e.embedding <=> :query_vector::vector(768)) >= :min_similarity
    ORDER BY e.owner_id, e.owner_table, (e.embedding <=> :query_vector::vector(768)) ASC
),
vector_matches AS (
    SELECT
        owner_id,
        owner_table,
        modality_composition,
        chunk_preview_text,
        cosine_sim,
        ROW_NUMBER() OVER (ORDER BY cosine_sim DESC) AS vec_rank
    FROM best_vector_per_item
    ORDER BY cosine_sim DESC
    LIMIT 40
),
raw_fts_matches AS (
    SELECT
        c.id AS owner_id,
        'captures'::varchar(32) AS owner_table,
        ts_rank_cd(c.search_tsv, websearch_to_tsquery('english', :query_text)) AS fts_score
    FROM captures c
    WHERE c.search_tsv @@ websearch_to_tsquery('english', :query_text)
      AND NOT c.is_deleted
      AND (:include_archived = TRUE OR NOT c.is_archived)
    UNION ALL
    SELECT
        s.id AS owner_id,
        'ai_sparks'::varchar(32) AS owner_table,
        ts_rank_cd(s.search_tsv, websearch_to_tsquery('english', :query_text)) AS fts_score
    FROM ai_sparks s
    WHERE s.search_tsv @@ websearch_to_tsquery('english', :query_text)
      AND NOT s.is_dismissed
),
fts_matches AS (
    SELECT
        owner_id,
        owner_table,
        fts_score,
        ROW_NUMBER() OVER (ORDER BY fts_score DESC) AS fts_rank
    FROM raw_fts_matches
    ORDER BY fts_score DESC
    LIMIT 40
),
fused AS (
    SELECT
        COALESCE(v.owner_id, f.owner_id) AS item_id,
        COALESCE(v.owner_table, f.owner_table) AS item_table,
        v.modality_composition,
        v.chunk_preview_text,
        COALESCE(v.cosine_sim, 0.0) AS semantic_similarity,
        COALESCE(f.fts_score, 0.0) AS keyword_score,
        (COALESCE(0.70 / (60 + v.vec_rank), 0.0) + COALESCE(0.30 / (60 + f.fts_rank), 0.0)) AS base_rrf_score
    FROM vector_matches v
    FULL OUTER JOIN fts_matches f
        ON v.owner_id = f.owner_id AND v.owner_table = f.owner_table
)
SELECT
    fused.item_id,
    fused.item_table,
    COALESCE(c.capture_type::text, 'ai_spark') AS item_type,
    COALESCE(c.title, c.extracted_title, s.title) AS title,
    COALESCE(fused.chunk_preview_text, LEFT(COALESCE(c.raw_text, s.spark_markdown), 400)) AS snippet,
    fused.modality_composition,
    fused.semantic_similarity,
    fused.keyword_score,
    -- Apply 1.15x boost when item matches an active project slug or tag in persona.json
    fused.base_rrf_score * (
        CASE
            WHEN s.related_project = ANY(:active_project_slugs)
              OR (c.auto_tags && :active_project_slugs)
              OR (c.user_tags && :active_project_slugs)
            THEN 1.15
            ELSE 1.0
        END
    ) AS rrf_score,
    COALESCE(c.captured_at, s.created_at) AS item_timestamp
FROM fused
LEFT JOIN captures c ON fused.item_table = 'captures' AND fused.item_id = c.id
LEFT JOIN ai_sparks s ON fused.item_table = 'ai_sparks' AND fused.item_id = s.id
WHERE (
    (fused.item_table = 'captures' AND NOT c.is_deleted AND (:include_archived = TRUE OR NOT c.is_archived))
    OR (fused.item_table = 'ai_sparks' AND NOT s.is_dismissed)
)
  AND (COALESCE(c.capture_type::text, 'ai_spark') = ANY(:filter_types))
ORDER BY rrf_score DESC
LIMIT :top_k;
```
